## Part 7: Decision Tree Visualization

In this step, the trained Decision Tree is visualized using Scikit-learn.

### Steps Performed

* Created a Decision Tree with a maximum depth of 3.
* Trained the tree using the training dataset.
* Used `plot_tree()` to visualize the tree.
* Displayed feature names and class names.
* Generated a graphical representation of the decision-making process.

### Purpose

Tree visualization helps understand how the Decision Tree makes classification decisions using different features and conditions.

### Result

A graphical Decision Tree is generated showing the decision nodes, branches, features, and predicted classes.
